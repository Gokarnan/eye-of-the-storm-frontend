EYE OF THE STORM — FRONTEND

Files:
- index.html: game with the Render WebSocket URL prefilled
- vercel.json: Vercel configuration

Prefilled WebSocket URL:
wss://eye-of-the-storm-backend.onrender.com

Deploy:
1. Upload these files to your frontend GitHub repository (index.html and vercel.json at the repository root).
2. Import that repository into Vercel and deploy.
3. Open the deployed game, choose Multiplayer, then create or join a room.

Note: The URL is prefilled, but multiplayer works only if the Render backend is running and supports WebSocket connections. If the game cannot connect, check the Render service logs.
